# Mercagi → LINCE CORE

Aplicación web para convertir el mensaje de pedido que Mercagi envía por WhatsApp en un archivo Excel compatible con LINCE CORE.

## Uso

1. Pega el mensaje completo de Mercagi.
2. Revisa los códigos y cantidades detectados.
3. Descarga el archivo .xlsx.

La aplicación admite hasta 100 productos por pedido. El Excel contiene las columnas CODIGO, CANTIDAD, TIPO y PRECIO; las dos últimas quedan vacías.

El procesamiento se realiza dentro del navegador y el mensaje no se almacena.
